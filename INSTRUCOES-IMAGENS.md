# Como adicionar as imagens reais dos produtos

1. Baixe o arquivo `vittabella-site.zip` que eu enviei anteriormente.
2. Extraia o ZIP.
3. No repositório GitHub (https://github.com/GuiiMarx/vitta-bella-imports):
   - Clique em **Add file → Upload files**
   - Arraste a pasta `products/` inteira e o arquivo `logo.png`
   - Commit

Pronto! As imagens reais dos perfumes (Asad, Yara, Fakhar) estarão no site.

O site já está 100% funcional. Basta ativar o **GitHub Pages** em Settings → Pages para publicar online.
